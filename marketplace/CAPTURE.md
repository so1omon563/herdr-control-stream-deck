# Demonstration video capture plan

The functional demonstration video is deliberately deferred from SO1-284.
This plan preserves the required content and privacy boundaries for the later
capture ticket.

## Output

- 1920 × 1080 MP4
- Under 250 MB
- Approximately 35 to 50 seconds
- Clean desktop and neutral Herdr workspace names
- No personal terminal history, credentials, notifications, or unrelated
  third-party branding

## Sequence

1. Show Herdr Control installed in Stream Deck.
2. Demonstrate workspace, tab, and pane navigation on Stream Deck +.
3. Rotate and press the four dials, including adaptive split-or-zoom behavior.
4. Show blocked and completed work on the Agent Attention key, then press it
   to focus an actionable agent pane.
5. Show the equivalent primary navigation on the 15-key Stream Deck, then open
   More and browse the full Agents folder.
6. End on both supported profiles and the Herdr Control mark.

## Capture checks

- Use the personal plugin UUID and current released package.
- Confirm both profiles match the committed sources before recording.
- Use generic workspaces and enough panes and agents to demonstrate state
  changes without exposing private content.
- Record hardware interaction and matching on-screen behavior in the same
  frame where practical.
- Review the final video at full resolution with audio muted unless narration
  is intentionally added.
